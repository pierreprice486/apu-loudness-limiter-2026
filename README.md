## Overview

APU Loudness Limiter is designed for audio tasks where dependable level control must be balanced with loudness goals and available peak headroom. By combining loudness limiting with true peak processing, it offers more controlled output behavior for mixing, mastering, and broadcast preparation.

The software is intended for Windows workflows and can be used either as a standalone program or through a plugin host. VST3 and AU compatibility, multi-channel processing, and low-latency operation make it suitable for production sessions and monitoring paths where accurate timing and level visibility are important.
